🚀 Características Principales
Mecánica de Memoria Clásica: Un tablero dinámico donde el jugador debe voltear fichas para encontrar parejas correspondientes entre palabras en inglés y sus referencias.

Sistema de Audio Remoto: Descarga y reproducción en tiempo real de archivos de audio multimedia desde el servidor (UnityWebRequest) para la correcta pronunciación de las palabras.

Interfaz de Usuario Sci-Fi: Paneles flotantes personalizados, efectos visuales de neón estructurados con TextMeshPro y diseño adaptado para una experiencia de usuario inmersiva.

Arquitectura Limpia: Separación de responsabilidades mediante controladores modulares (GestorTablero y ControladorFicha) para la gestión de estados, eventos táctiles y validación de niveles.

Multiplataforma: Optimizado para su compilación y despliegue en dispositivos móviles Android (APK).
